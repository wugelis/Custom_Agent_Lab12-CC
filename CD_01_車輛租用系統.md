# CD_01 車輛租用系統 — Class Diagram

```mermaid
classDiagram
    class Account {
        +username : String
        +password : String
        +registerAccount(accountInfo : AccountInfo) Boolean
        +login(username : String, password : String) Boolean
    }

    class RentalOrder {
        +selectedCar : Car
        +startDate : Date
        +endDate : Date
        +totalRent : Float
        +confirmed : Boolean
        +toRentalCar() void
        +setRentalPeriod(startDate : Date, endDate : Date) void

    }

    class Car {
        +carType : String
        +dailyRate : Float

    }

    RentalOrder --> Car : 持有已選車輛並取得每日租金以計算總租金
```

---

## 補充說明

| Class 名稱 | 中文名稱 | 職責說明 |
|------------|----------|----------|
| Account | 帳戶 | 負責租車用戶的帳戶註冊（RegisterAccount）與登入驗證（Login） |
| RentalOrder | 租車訂單 | 預約租車流程的核心類別，負責啟動租車（ToRentalCar）、設定租用時間區間、計算租金與確認租車 |
| Car | 車輛 | 代表可租用的車輛，提供車型選擇（SelectCarType）與每日租金查詢（GetDailyRate） |
